## 👋 About Me

Hi, I'm **Jindong Hwang (황진동)**, an M.S. student working at the intersection of **artificial intelligence and materials science**.

Coming from an AI background, I bring LLMs and machine learning into materials research: mining the literature, learning from sparse experimental records, and letting AI agents run simulations and lab equipment.

- 🔬 **[Materials AI Modeling Laboratory](https://msquare-csb.github.io/Homepage/)**, Sungkyunkwan University · Advisor: Prof. Sung Beom Cho
- 🧠 **[iKnow Lab](https://iknow.ajou.ac.kr/)**, Ajou University · Co-advisor: Prof. Hyunsouk Cho

## 🔭 Research Interests

- **LLM Agents for Science**: language models that operate simulation software and laboratory instruments
- **Materials Informatics**: learning process–property relationships from sparse, mostly-positive experimental data
- **Literature Mining**: extracting sample-level process and property data from both the text and the figures of papers
- **Autonomous Experimentation**: Bayesian optimization and self-driving laboratories
- **Materials Foundation Models**: domain-adaptive pre-training for materials science

## 🧪 What I'm Working On

| Project | Description |
|:--|:--|
| 🧲 **Ferroelectric recipe screening** | Predicting which process recipes yield ferroelectricity when failed experiments are rarely recorded (positive–unlabeled learning), used to screen candidates in a Bayesian optimization loop for HZO thin films |
| 🖥️ **LLM × COMSOL Multiphysics** | Probing how far an LLM's decision-making can drive a multiphysics simulator, as a step toward digital twins for autonomous labs |
| ⌨️ **Hardware-level GUI agent** | An LLM agent that reads an instrument PC's screen and operates it through KVM keyboard/mouse emulation, for equipment that has no API |
| 📚 **Sample-level literature database** | Reading the text and plots of papers together to build per-sample process–property records |
